# 📊 StockWise

A Python-based stock portfolio tracker for managing investments and monitoring portfolio performance.

## Features

- Add, update, remove and search stocks
- Calculate investment, current value and profit/loss
- Identify best and worst performing stocks
- View portfolio insights
- Track investment goals
- Maintain transaction history
- Terminal-based performance graph
- JSON-based data storage

## Technologies

- Python
- JSON
- File Handling
- Exception Handling
- Functions

## How to Run

```bash
python main.py
