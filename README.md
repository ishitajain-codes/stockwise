# StockWise

StockWise is a Python-based stock portfolio management project designed to help users manage their investments and understand their portfolio performance.

## Features

- Add and manage stocks
- Track investment details
- Calculate profit and loss
- View portfolio insights
- Store portfolio data using JSON
- Handle invalid inputs and common errors
- Display portfolio performance using graphs

## Technologies Used

- Python
- JSON
- File Handling
- Exception Handling
- Data Visualization

## Project Structure

The project is organized into different Python modules to keep the code clean, readable, and easy to maintain.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Make sure Python 3.x is installed.
4. Run the main Python file.
5. Follow the options shown in the menu.
